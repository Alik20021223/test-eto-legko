# speedtest-cli

[English](README.md) | **Русский**

Консольная утилита для замера скорости скачивания. Делает 10 последовательных HTTP-запросов к указанному адресу, дожидается полного ответа на каждый и выводит среднее время запроса, общий объём скачанных данных и скорость скачивания.

Без зависимостей, только стандартная библиотека Node.js.

## Требования

Node.js 18 или новее (используется встроенный `fetch`).

## Запуск

```bash
git clone <repo-url>
cd speedtest-cli

# тестовый файл по умолчанию (~2 МБ с Cloudflare)
node bin/speedtest.js

# свой адрес, например тяжёлая картинка
node bin/speedtest.js https://example.com/big-image.jpg

# параметры
node bin/speedtest.js https://example.com/big-image.jpg -n 5 -u MB/s -t 60
```

Также работает через `npm start -- <url>`.

| Параметр | Описание | По умолчанию |
| --- | --- | --- |
| `[url]` | адрес для скачивания (http или https) | файл 2 МБ с Cloudflare |
| `-n, --requests` | количество запросов | `10` |
| `-u, --unit` | единица скорости: `Mbps`, `MB/s`, `KB/s` | `Mbps` |
| `-t, --timeout` | таймаут одного запроса, секунды | `30` |
| `-h, --help` | справка | |

Коды выхода: `0` успех, `1` все запросы завершились ошибкой, `2` неверные аргументы.

## Единицы измерения

По умолчанию скорость выводится в **Mbps (мегабиты в секунду)**, так её указывают интернет-провайдеры.
Везде используются десятичные приставки: 1 Mbps = 1 000 000 бит/с, 1 MB/s = 1 000 000 байт/с, поэтому **1 MB/s = 8 Mbps**.
Другие единицы доступны через `--unit`: `MB/s` и `KB/s`.

## Как считается скорость

- Запросы идут строго по очереди: следующий начинается только после того, как тело предыдущего прочитано полностью.
- Время запроса считается от отправки до получения последнего байта (`performance.now()`).
- Скорость = общий объём / суммарное время успешных запросов. Это не среднее арифметическое скоростей отдельных запросов, поэтому медленный крупный запрос учитывается корректно.
- Неудачный запрос (таймаут, сетевая ошибка, статус не 2xx) выводится в лог и пропускается, прогон продолжается. В статистику такие запросы не входят.

## Структура проекта

```
bin/speedtest.js          точка входа (3 строки)
src/
  config.js               значения по умолчанию
  errors.js               UsageError, HttpStatusError
  core/                   логика, без вывода в консоль
    HttpClient.js         полностью скачивает URL, возвращает байты и время
    BenchmarkRunner.js    N последовательных запросов, сбор замеров
    stats.js              чистая функция: замеры -> итоги
    units.js              конвертация единиц и форматирование размера
  cli/                    всё, что связано с консолью
    args.js               разбор и валидация аргументов
    report.js             текстовое оформление прогресса и итогового отчёта
    run.js                связывает части вместе, отвечает за вывод в консоль
test/                     node:test, включая локальный HTTP-сервер
```

Ядро ничего не знает о консоли, а CLI ничего не знает о том, как делаются запросы. `BenchmarkRunner` получает HTTP-клиент снаружи, поэтому тестируется без сети.
